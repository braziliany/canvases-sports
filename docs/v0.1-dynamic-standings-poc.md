## 已验证的 Canvas 约定

当前 Canvas：`苏超`

```text
standings-grid
└── team-row [Template]
    ├── rank
    ├── team-name
    ├── goal-difference
    └── points
```

- `standings-grid`：动态容器，`Template Children = ON`。
- `team-row`：每支球队的模板根 View。
- `rank`：排名。
- `team-name`：来自 `Repeat Item → team → name`。
- `goal-difference`：净胜球原始数值；正数加号属于后续 UI 处理。
- `points`：积分。

## 最终 Shortcut 数据流

```text
Get Contents of URL
↓
Get Dictionary Value: standings
↓
Repeat with Each Item in standings

    Repeat Item
    ├── rank → currentRank
    ├── team → name → currentTeam
    ├── goalDifference → currentGoalDifference
    └── points → currentPoints

    Create View from Template
    ↓
    Update rank.Text = currentRank
    ↓
    Update team-name.Text = currentTeam
    ↓
    Update goal-difference.Text = currentGoalDifference
    ↓
    Update points.Text = currentPoints
    ↓
    Final Updated View

End Repeat
↓
Repeat Results
↓
Update standings-grid.Children
↓
Widget
```

## 核心技术结论：View Update 必须链式传递

`Update View Created from Template` 不是对一个共享 View 引用进行可随意并行的原地修改。每次 Update 的输出 View 必须成为下一次 Update 的输入。

错误：

```text
             ┌→ Update rank
Created View ├→ Update team-name
             ├→ Update goal-difference
             └→ Update points
```

正确：

```text
View0 = CreateView()
View1 = Update(View0, rank)
View2 = Update(View1, teamName)
View3 = Update(View2, goalDifference)
View4 = Update(View3, points)
FinalView = View4
```

每轮 Repeat 的最后输出必须是 `FinalView`，这样 `Repeat Results` 才是 13 个已完整更新的根 View 列表。

## Debugging Lessons

1. 使用 `Repeat with Each Item in standings`，不要优先采用 `Repeat 13 Times + Repeat Index`。
2. `Repeat Item` 直接代表当前球队记录；无需在循环中再次按索引取项。
3. `team` 是嵌套 Dictionary，球队名必须通过 `team → name` 读取。
4. 多个“字典值”Magic Variable 容易串引用；及时保存为 `currentRank`、`currentTeam`、`currentGoalDifference`、`currentPoints`。
5. 用 Quick Look 逐轮检查变量，先把 JSON/Repeat 问题与 View 渲染问题隔离。
6. 动作在界面上连续排列，不代表后一个动作的 View 参数自动引用前一个动作的输出。
7. `Repeat Results` 必须收集每轮最终完成全部字段更新后的 View。
8. “13 行全部是无锡”是错误 View 引用链的典型症状；数据逐轮变化不代表 View 链接正确。
