### Phase 3 · Shortcuts + Grid Template 正式方案

完成：

- 根据用户提供的官方 User Guide 摘要，确认 Canvases 使用 Visual Editor + Shortcuts，无应用内代码 Runtime。
- 将正式数据流修正为 GitHub JSON → iOS Shortcut → Canvases Grid Template → Widget。
- 定义稳定 View IDs、Canvas View Tree、一列 Grid、Template Children 和动态 TOP 8 逻辑。
- 编写可在 iPhone 上逐步搭建的 Canvas 与 Shortcut 实施文档。

发现：

- Web `fetch`/`localStorage` 仅属于参考实现，不能作为 Canvases 原生能力。
- 真机 Canvas 可以立即收到更新，但 Home Screen Widget 仍受 iOS 刷新预算影响。

问题：

- 官方 User Guide 原文件尚未随任务附件进入仓库；当前只使用用户提供的 Guide 摘要，不扩展未确认 API。
- Canvas、Shortcut、Widget 和分享链接仍需在 iPhone 上创建和验证。

下一步：

- 按 `docs/canvas-template.md` 和 `docs/shortcut.md` 完成设备搭建。
- 保存无敏感信息的真机截图，记录正常网络、断网和无效 JSON 测试。
