# 技术架构

> 能力依据：用户提供的官方 Canvases User Guide 摘要。User Guide 原文件尚未进入仓库，因此本文不会扩展摘要之外的 API。

## 正式架构

```text
江苏省体育局官方积分榜图片
          ↓ 人工复核转录（v0.1）
Jiangsu League Adapter
          ↓
Unified Standings Schema + Validation
          ↓
data/standings.json
          ├─→ iOS Shortcut
          │        ↓ Canvases Shortcuts Actions
          │   Grid + Template Children
          │        ↓
          │   Home Screen Widget
          │
          └─→ Web Reference Renderer
                   （调试 / 数据校验 / 桌面预览）
```

Canvases 不是代码 Runtime。布局在 Visual Editor 中完成，实时数据由 Shortcuts 获取并通过 Canvases Actions 写入具有稳定 ID 的 Views。

## 官方能力基准

已由 Guide 摘要确认：

- Visual Editor；
- Text、Stack、Grid、Divider、Spacer、Button、Image、Symbol、Progress、Chart；
- View ID；
- `Update View`；
- `Create View from Template`；
- `Update View Created from Template`；
- Grid Template Children；
- Shortcuts Automation；
- CloudKit 同步。

不再设计或声称存在 Canvases JavaScript/TypeScript/DSL Runtime、Canvases Network API、Canvases JSON API 或 Canvases `localStorage`。

## 代码与设备边界

- `src/leagues/jiangsu/`：来源适配和联赛规则。
- `src/core/`：Schema 校验、通用逻辑和 Web 参考能力。
- `data/standings.json`：Shortcuts 与 Web 共用的稳定合同。
- `src/canvases/jiangsu-standings.js`：Web 参考渲染器使用的派生 View Model，不是 Canvases Runtime 代码。
- `docs/canvas-template.md`：真机 Visual Editor 搭建规范。
- `docs/shortcut.md`：真机 Shortcuts 搭建规范。

## 更新与失败策略

Shortcut 从 GitHub Raw 获取 `data/standings.json`，先检查字典、`updatedAt` 和 13 行 standings，再创建全部模板行。只有所有行构建成功后，才一次性替换 `standings-grid` 的 Children，并更新 Header。

网络或数据校验失败时停止 Shortcut，不清空 Grid。Canvases/CloudKit 中上一次成功写入的 Views 继续显示。这是 v0.1 的“保留最后成功画面”策略，不等同于自定义本地缓存 API。

Home Screen Widget 的可见更新时间受 iOS 系统预算影响。Canvas 可立即更新，但 Widget 通常可能延迟约 15–60 分钟；文档和测试应将其视为平台限制。

## Web Reference

Web 实现继续使用浏览器 `fetch`、`localStorage`、async/await 和响应式表格。它只用于调试、校验和桌面预览，这些浏览器能力不得写入 Canvases 真机实施步骤。

## Superseded

此前的 `Canvases Native Renderer`、HTTP Probe 和应用内代码 Runtime 方向，源于缺少官方 Guide 时的保守集成假设。Guide 摘要确认无代码工作流后，该方向已废弃；历史原因保留在 ADR 中。
