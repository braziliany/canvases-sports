# 技术架构

```text
江苏省体育局官方积分榜图片
          ↓ 人工复核转录（v0.1）
Jiangsu League Adapter
          ↓
Unified Standings Schema + Validation
          ↓
data/standings.json
          ↓
Fetcher → Validate → Cache → Canvas View Model → Renderer
                         ↘ failure: Cache → Renderer
```

## 边界

- `src/leagues/jiangsu/` 只处理江苏联赛来源和规则。
- `src/core/` 提供抓取、校验、缓存和通用排名工具。
- `src/canvases/` 输出平台无关 View Model，不猜测未确认的原生 API。
- `src/ui/` 是可运行的 Web 参考渲染器。

## 刷新与缓存

页面打开自动刷新，用户也可手动刷新。响应先经过 Schema 校验，成功后写入 `localStorage`；网络或响应失败时验证并显示最后一次成功缓存。没有缓存时显示不可用状态。

## Canvases 能力调查结论

目标产品已经确认：Scriptable 开发者推出的 Canvases TestFlight Beta，邀请地址为 `https://testflight.apple.com/join/65RCk8Xh`。Apple 的邀请页将其描述为可设计小组件并通过 Shortcuts 更新的应用。

Windows 工作区、用户同步目录、公开邀请页和开发者公开资料中均未发现项目导出文件、官方示例、SDK、DSL 或 API Reference。因此网络、JSON、异步、缓存、定时刷新、点击、布局、图片、字体、颜色、条件样式和日期格式化等“原生 Canvases 能力”仍不能宣称已验证。

当前 Web 参考实现已验证浏览器能力：`fetch`、JSON、async/await、`localStorage`、点击刷新、响应式表格、颜色/条件样式和 `Intl.DateTimeFormat`。定时高频刷新未实现。

## 与 Scriptable 的差异

Canvases 与 Scriptable 来自同一开发者不代表 API 相同。Web 参考实现运行在浏览器安全模型中；Scriptable 是 iOS JavaScript 自动化运行时并提供原生模块。没有 Canvases 的真实资料前，两者 API 不能互换。
