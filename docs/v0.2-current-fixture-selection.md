# v0.2 Current Fixture Selection

## 数据职责

```text
Official Schedule Source
→ canonical fixtures
→ runtime fixture projection (device `now`, Asia/Shanghai)
→ selected fixtures
→ Shortcut
→ Canvases
```

赛程是赛前事实；赛果是赛后事实。Current Fixture Selection 不读取 ResultCandidate，不推断终场，也不参与积分结算。`fixtures` 保存权威赛程和历史赛果。当前比赛周是运行时投影，必须在每次 Shortcut 执行时根据设备当前时间重新生成。

## 选择合同

按 `round` 分组，并以该周最早 kickoff 为边界。默认提前 24 小时切换到下一比赛周：

- 第一组比赛前：显示最近未来周；
- kickoff 起至下一周切换窗口前：显示本周；
- 本周已全部进入明确终态：仍显示最近结束周；
- 下一周 kickoff 前 24 小时：切换到下一周；
- 最后一周之后：继续显示最后一周。

选择只依赖运行时 `now`、带 `+08:00` 的 Asia/Shanghai kickoff 与赛历，不依赖“最后一个有比分的比赛”。`scheduled` 到达 kickoff 后仅派生 `effectiveStatus: live`；时间绝不派生 `finished`。

确定性 season-flow 回归连续覆盖 9 月 5 日赛前/赛中/赛果结算、9 月 11 日 19:39 与 19:40 的切换边界、9 月 12 日部分和全部完赛、9 月 18 日切换边界，以及 9 月 19 日/21 日最后一轮。最后一轮完成后仍保留第 22 周，不返回空列表或旧轮次。

## Canonical、runtime-derived 与 build-time preview

- Canonical facts：`fixtures` 内的赛程、主客队、kickoff、原始 `status`、已审核比分与 provenance。
- Runtime-derived state：本次运行的 `effectiveStatus`、`displayRound`、`displaySelectionReason` 与 selected fixtures。
- Build-time preview：根级 `effectiveStatusAt`、逐场 `effectiveStatus`、`displayRound`、`displaySelectionReason`、`displayFixtures`。这些字段仅为旧客户端兼容和诊断快照，不得再作为生产展示真值。

根级 `runtimePresentation` 是可校验的静态策略合同：输入字段为 `fixtures`，时区为 `Asia/Shanghai`，下一轮提前 24 小时切换，旧 preview 明确标记为 `build-time-only`。

`deriveRuntimeFixturePresentation` 是 JS 侧唯一规则实现。回归场景固定输入和预期输出，供 Shortcut 等价实现验收，避免规则漂移。

`tests/fixtures/runtime-presentation-scenarios.json` 保存 JS 与 Shortcut 共用的固定时间、期望轮次、状态和 9 月 11 日现场六场清单。

## 兼容预览刷新

```bash
npm run fixtures:sync -- --dry-run
npm run fixtures:sync -- --dry-run --now=2026-09-11T19:40:00+08:00
```

`fixtures:sync` 仍可刷新旧客户端所需的构建时 preview。它是兼容设施，不再是 Season Flow 正确性的前提；Action 不运行、仓库无新 commit 时，新客户端仍会随设备时间正确切换。Fixture 与 Result 两个 Action 继续使用同一并发组，避免同时写开发分支。

## Shortcut 合同

生产 Shortcut 必须从根级 `fixtures` 生成本次运行的 selected fixtures，不能再直接 Repeat 静态 `displayFixtures`。实现保持最小化：按已有顺序扫描各轮最早 kickoff；当设备时间到达该轮最早 kickoff 前 24 小时时，将该轮设为当前轮；随后过滤该轮。每场只做允许的状态投影：显式 `finished/postponed/cancelled/live` 原样保留，`scheduled` 仅在 `now >= kickoff` 时显示为 `live`。

kickoff 必须读取已有带 `+08:00` 的 ISO 字段，不在设备端拼接本地日期。模板 ID、子 View ID 与 ADR-006 链式 Update View 规则不变；当前轮的 Repeat Results 更新 `fixtures-grid.Children` 后，继续沿原 View 输出链更新 standings，一次运行完成全部写入。

迁移完成前旧 Shortcut 仍可读取 legacy preview，但无法满足“无新 commit 自动切换”的 Gate。
