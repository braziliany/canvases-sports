# 苏超积分榜设计

## 字段

排名、趋势、球队、已赛、胜、平、负、进球、失球、净胜球、积分、更新时间和来源。

趋势定义为 `previousRank - rank`。官方来源没有可靠的 `previousRank` 字段，因此 v0.1 存储 `null`，UI 显示 `—`。

## UI

深色、克制、高密度。排名 1–8 使用淡绿色状态，8 与 9 之间插入“TOP 8 · 晋级淘汰赛”分界线。移动端允许表格横向滚动，保证字段不被错误折叠。

## 排名与晋级

展示官方排名。通用排序函数仅用于无相互战绩数据的测试/候选集合，不能覆盖官方同分排序。前八名进入淘汰赛。

## 状态

- Loading：正在更新积分榜。
- Network Error：显示已验证缓存并提示。
- No Cache：暂时无法获取比赛数据。
- Invalid Data：拒绝渲染无效响应，不让 UI 崩溃。

## 刷新

打开自动刷新，按钮手动刷新；v0.1 不做高频定时请求。
